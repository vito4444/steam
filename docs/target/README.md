# 视觉目标基准

这两张图是《暗市镇》的视觉对标，用于在开发过程中把实际游戏截图与目标并排比较。它们是概念稿，不是可直接使用的美术资源。

## target_surface_layer.png — 地表层的完整对标

这张图定义了地表层的全部视觉要求，实现时逐项对照：

- 俯视 45 度伪等距，32×32 像素格，暖色土黄与木色主调
- 建筑轮廓清晰可辨：伐木场带原木堆、黏土坑、麦田、酒厂带酒桶、仓库、茅草顶住房
- 巡查员为高饱和红色制服，在暖色地表上一眼可见
- 建筑后方的超量土堆是可见的暴露风险（图中山丘状裸土）
- HUD 四区：季节时钟表盘、怀疑度条、资源账目数字栏、建造菜单图标格

## target_under_layer.png — 氛围与 HUD 布局的对标

**这张图的视角不作为实现目标。** 它画的是侧剖面，而游戏的地下层将采用与地表相同的俯视视角、按深度分层（Level 1 至 Level 5），原因是「把密室挖在巡查路线覆盖不到的位置」这个核心决策需要地表与地下的 XY 坐标能够对齐，侧剖面会让其中一个水平维度消失，空间博弈随之失效。

采纳这张图的是另外两点：

- **色调方案**：冷蓝灰的岩层配合火把形成的暖橙色光池，冷暖对比本身承担照明与可视范围的信息传达
- **HUD 布局**：左侧季节时钟加时段文字（Winter / Night / 3rd Watch），中左怀疑度条带百分比数字与状态文字（Guards Unaware），中右账本表格分列收入支出结余，右侧建造菜单。这个四区布局比第一张图更清晰，作为 UI 实现的参照
