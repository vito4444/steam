# Progress log

One entry per milestone. Every entry carries the self-check screenshots for that build
beside the concept art target, the measured gap between them, the performance metrics, and
an explicit list of what is still missing.

The screenshots are captured by the game itself through the automated harness described in
`docs/tech/build-pipeline.md`. None of them are hand-composed or retouched.
