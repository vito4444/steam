# 搭配画板契约（CERE-21）

模特视图回答「穿上去什么样」，画板回答「这一套都有哪几件、每件长什么样」。
两者并存、共用同一份衣橱数据与同一套 Look 存储，画板不另立素材 schema。

## 1. 数据结构

`src/shared/board.ts`：

```ts
BOARD_CANVAS = { w: 1400, h: 1800 }      // 画板自己的坐标系，与模特底图画布无关

BoardItem {
  id, kind: 'asset' | 'text',
  assetId?,                              // kind='asset' 时指向衣橱素材 id
  text?, font?, color?,                  // kind='text'
  x, y,                                  // 中心点（画布坐标）
  w, h,                                  // 未旋转时的包围盒
  rotation, z, flipX?
}

BoardLook { version: 1, canvas, background, items }
```

记中心点而不是左上角：缩放和旋转都绕中心，拖动时参考点不漂移。

Look 上新增两个可选字段（`src/shared/types.ts`）：

- `kind?: 'model' | 'board'` —— 缺省是 `model`，老 Look 不用迁移；
- `board?: BoardLook` —— 画板布局。

画板 Look 的 `slots` 照样按槽位填素材 id（同槽位多件时取 z 最高那件），
所以一套画板 Look 也能被模特视图载入试穿。落盘仍走 `looks:save`，
主进程不认识 `board` 字段也能原样存下来。

## 2. 无遮挡是硬约束

需求第一条验收：每件单品从上至下清晰展示、互不重叠。实现方式是不给「自由摆盘」
留口子 —— 自动布局是两列严格纵向排列：

| 列 | 内容 | 顺序 |
| --- | --- | --- |
| 主列（左，58% 宽） | 外套 → 上装 / 连衣裙 → 内层 → 下装 → 袜打底 → 鞋 | 从上到下 |
| 副列（右，32% 宽） | 帽 → 眼镜 → 围巾 → 包 → 腰带 → 手套 → 其他 | 从上到下 |

只有一列有内容时它吃满宽度。每件的高度按品类权重分配列高，
单件按这个高度会超出列宽时改由列宽反算高度；整列偏高就整体缩小，
偏矮就整体放大（放大受列宽约束，最多 1.35 倍），最后垂直居中。

- **纵向排列天然不重叠**，重叠只可能来自手动拖拽。
- `findOverlaps()` 是唯一判据（旋转后的 AABB 相交面积 / 较小件面积 > 2%），
  界面右上角常驻「布局自检」，不让人肉眼判断。
- `separate()` 是兜底：手动摆乱之后点「整理」，沿相交较浅的那条轴推开，
  宁可留白也不叠。
- 「穿着感重叠」滑杆默认 **0**；拉高也只允许上装衣摆压住下装腰头，
  上限是较小件高度的 12%，且只作用于主列里相邻的上装 / 下装这一对。

回归检查：`npm run check:layout` 跑 2000 组随机搭配（1–9 件，长宽比 0.2–4.5），
断言无遮挡、无越界、主列顺序正确。

## 3. 渲染

`paint.ts` 是唯一的绘制实现：

- 背景（纯色 / 纸纹 / 亚麻 / 细格 / 渐变 / 深灰）画进 canvas。屏幕上的画板背景
  也是同一个函数画的 —— 不维护 CSS 与 canvas 两份实现，「所见即导出」不靠人肉对齐。
- 单品在屏幕上是 DOM（拖拽、旋转手柄要 DOM 命中测试），导出时按同样的变换
  重画进 canvas。
- 噪点用固定种子伪随机，否则每次重绘纹理都在抖。
- `renderBoard(board, assets, scale, { crop })`：`scale` 1 = 1400×1800，导出 2× / 3×；
  `crop: 'content'` 按元素外接矩形裁剪，Look 封面用它，卡片上才是拼贴本身而不是空白。
- 素材被删了就跳过那一件，不画破图。

## 4. 与其他线的边界

- **不动模特渲染**：`render/`、`tryon/`、`features/stage/`、`features/dressing/`
  一个字没改（CERE-14 在这些文件上做遮挡与贴合）。画板状态也刻意不进
  `state/store.tsx`，自己起 `BoardProvider`。
- 共享文件只碰了必须碰的：`shared/types.ts`（加两个可选字段）、
  `state/store.tsx`（View 联合类型加 `'board'`）、`App.tsx`（导航项）、
  `main.tsx`（挂 Provider）、`features/views/Views.tsx`（Look 库加场景筛选）、
  `shots.ts`（加画板场景）、`ui/icons.tsx`（加一个图标）。
- **不产素材、不做 AI 生图**。画板只摆已有素材。
- 拼贴质量的上限是抠图质量：素材边缘残留的白底会在纸色背景上看得见，
  那是素材管线（CERE-12 / CERE-13）的范围，画板不做二次抠图。

## 5. 交互

| 动作 | 操作 |
| --- | --- |
| 加入 / 移出 | 左侧衣橱点一下 / 再点一下 |
| 移动 | 拖拽，靠近画布中线或其他单品中心时吸附并显示参考线 |
| 缩放 | 选中框右上角方块，或右侧「大小」滑杆 |
| 旋转 | 选中框右下角圆钮（接近 90° 吸附），或「旋转」滑杆 |
| 删除 | 选中框左上角 ×，或 Delete / Backspace |
| 层级 | 右侧「置顶 / 上移 / 下移 / 置底」 |
| 微调 | 方向键 4px，Shift + 方向键 20px |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Shift+Z（或 Ctrl+Y），整块快照栈，深度 60 |
| 标题 | 加标题后双击改文字，可换字体、拖动、旋转 |
