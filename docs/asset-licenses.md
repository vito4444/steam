# 第三方资产来源与许可登记

Steam 发行要求项目中所有资产的权利清晰可证。本文件登记项目使用的每一项非自制资产。

**规则：**

1. 不使用任何来源不明的资产。
2. 每引入一项第三方资产，必须在下表登记来源 URL、许可类型与引入日期。
3. 优先顺序：代码程序化生成 > CC0 / 公有领域 > 明确购买或授权的资产。
4. AI 生成的概念图仅用于内部方向对齐与文档说明，**不作为游戏内资产使用**。
