# CERE-24 真实窗口验收

以下五张图由 `electron . --shots` 的真实窗口 `capturePage` 生成；每个场景均先回到衣橱的模特试穿页、清空搭配与对比态，并恢复遮挡开 / 非原始叠图。素材通过 `wearIds` 的既有别名解析为当前 CERE-13 bundled wardrobe，不修改衣橱索引或 PNG。

## 复现

```powershell
$env:PIXELFIT_ROOT='.testdata/cere24'; $env:PIXELFIT_SHOT_SCENES='fit_dress,fit_layered,fit_accessory,fit_shoes,fit_separates'; npm run shots
```

验收运行采用失败关闭：未知场景、未就绪、配方缺素材或任一场景截图异常都会在尝试其余
已请求场景后以非零状态退出，不能用缺件或缺图的“成功”结果交付。
